记点儿 隐私政策

生效日期：2026年10月7日  |  更新日期：2026年10月7日

「记点儿」（以下简称"本应用"）是一款由个人开发者开发的本地记账应用。我们非常重视您的个人信息和隐私保护。本隐私政策将说明本应用如何收集、使用、存储和保护您的信息。请您在使用本应用前仔细阅读本政策。

核心承诺：本应用无账号体系、无广告、无统计埋点 SDK，您的全部记账数据仅存储在您的设备本地，我们不会以任何形式将您的数据上传至我们的服务器（我们也没有服务器）。

一、我们收集和处理的信息

信息类型使用目的处理方式

二、AI 智能解析功能的特别说明

本应用提供可选的「AI 智能解析」功能。该功能需要您自行填写第三方大模型服务商（如 DeepSeek、OpenAI 等）的 API 地址和密钥后方可使用，默认处于关闭状态。

当您开启并使用该功能时，记账相关的文本内容（如语音识别结果、OCR 识别结果）将通过您配置的 API 地址发送至您所选择的第三方服务商进行解析。该等数据传输发生在您的设备与第三方服务商之间，不经过本应用开发者。第三方服务商对数据的处理受其自身隐私政策约束，请您在使用前阅读并理解相应服务商的隐私政策。您可以随时在应用内关闭该功能或清除接口配置。

四、信息的存储与安全

  • 您的全部记账数据存储于您设备的应用私有目录中，其他应用无法访问。
  • API 密钥等敏感配置经加密后存储。
  • 卸载本应用将删除全部本地数据（包括加密的接口配置），且不可恢复。建议您在卸载或换机前使用应用内的「导出数据」功能备份。

五、信息的共享与披露

我们不会向任何第三方共享、出售或出租您的个人信息。唯一的例外是上述第二条中，由您主动配置并启用的 AI 智能解析功能所产生的、发往您自选第三方服务商的数据传输。

六、您的权利

  • 访问与导出：您可以随时在应用内查看全部记账数据，并通过「导出数据」功能导出为 CSV 文件。
  • 删除：您可以在应用内逐条删除记账记录，或通过卸载应用删除全部数据。
  • 撤回授权：您可以在系统设置中随时关闭麦克风等权限，不影响已存储的本地数据。
  • 账号注销：本应用无账号体系，不涉及账号注销，卸载应用即完成全部个人信息的删除。

七、儿童个人信息保护

本应用不面向 14 周岁以下儿童提供服务，不会有意收集儿童的个人信息。如果您是儿童的监护人并发现儿童使用了本应用，请联系我们删除相关信息。

八、本政策的更新

我们可能适时更新本隐私政策。更新后的政策将在本页面公布，重大变更时我们将在应用内向您提示。政策更新后您继续使用本应用，即视为接受更新后的政策。
